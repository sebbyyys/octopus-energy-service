# Octopus Energy Service

Private UK Octopus Energy API with persistent SQLite history, delayed readings,
and estimated costs. Experimental Home Assistant OS app for amd64 and aarch64.

Configure a private service token of at least 32 characters before starting.
Both supplier credentials are optional together; leaving both blank enables offline mode.
No ingress UI, host networking, elevated API permissions or default LAN port publication.

See the Documentation tab for installation, pairing and backup instructions.
